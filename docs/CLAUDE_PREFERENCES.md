## 予定・タスク（Notion）

- 予定・タスクの正本は Notion の **「タスク管理（GTD） > Tasks」DB**。ClickUp は使わない。
- 「予定を入れて」「タスクを追加して」「〇〇したい」「スケジュールして」→ Tasks にページを作成する。
  - `Name` タスク名 / `Status` 日時が決まっていれば `Remind`・未定なら `Inbox` /
    `期限` 日時（終了時刻は end に）/ `Tag` 下記 / `優先度` 高・中・低 / `固定` 動かせない予定は ON
  - Tag: 実験→`実験`+`QPI` ／ コード・解析・計画→`QPI` ／ 論文・原稿→`原稿` ／
    勉強・論文読み→`STUDY` ／ ミーティング・発表→`MEETING` ／ 事務・申請・連絡→`ADMIN` ／
    バイト・勤務→`仕事` ／ 部活・jog・weight→そのまま ／ 私生活→`プライベート`
- 時間未指定→12:00〜14:00。「午前」→9:00〜12:00。「午後」→13:00〜16:00。
- **「いつ空いてる？」と聞かれたら、Notion Tasks と Google カレンダーの両方を必ず見る。**
  utelecon の勤務は Notion にしかなく、ご飯・部活などはカレンダーにしかないことがある。
  空き確認だけのときはタスクを作らない。
- その日の動き方は**朝の秘書（morning brief）が出した予定**に従う。勝手に組み直さない。
- `固定` が ON の予定（部活・授業・会議・発表）は自動で動かさない。
- 「アラーム」「通知して」「リマインド」「〇時に知らせて」→ Siri に設定するよう案内する。

## 研究ノート・思考メモ（Notion 自動保存）

以下に該当したら確認せず Notion に保存する：

- 実験・測定・解析・光学系・データの観察や考察
- アライメント・RI・位相・PDMS・Bonding など研究固有語を含む発言
- 「〇〇が原因では」「〇〇を変えたら改善するかも」などの推測・改善案
- 「メモ」「気がする」「仮説」「気づいた」「アイデア」

保存しない：ツール設定・コードの文法・純粋な日常会話・ルールや設定の変更に関する議論。

### 1日1ページルール（Type ごと）

保存前に当日の既存ページを Type と日付で検索する。
見つかった → 区切り線＋内容を追記。見つからない → 新規作成。

- Type `思考メモ`：研究上の気づき・仮説・アイデア
- Type `作業ログ`：「Notion にまとめて」と言われたとき

タイトルは会話のテーマを一言で（プレフィックス不要、日付は Date プロパティ）。Type を必ず設定する。

### 本文の形

思考メモ：

```
## HH:MM | [気づき一言]
[内容]
**文脈:** 何をやっていたときか
**次に試すかもしれないこと:** 〜かもしれない
```

作業ログ：

```
## 何をしたかった
## 何ができた
## 作成・変更したファイル（具体的に）
## 考えたこと・判断したこと
## 図（あれば）
## フィードバック（空欄）
```

ルール：ユーザーの言葉をそのまま使う。断定しない。「次回やること」「残タスク」のセクションは作らない。

### 保存後

関連する過去メモを Notion で検索して提示する。概念を展開して2〜3クエリで検索し、
「完全に同じ」「一部重なる」「参考になるかも」の3段階で提示する。
