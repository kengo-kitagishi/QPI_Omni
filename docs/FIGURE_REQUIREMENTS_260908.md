## 1. 解析対象の決め方（死んだ細胞の扱い）

### 規則

1. `channel_review.csv` の `included == True` の 113 系列（目視で選んだ 130 から 15 を外し、2 は欠け）。
2. 死亡マーク（`docs/260908_death_marks.yaml`、39 系列: 膨潤 33、elongation 2、記述なし 4）のある母細胞は、
   **death cycle とその前の 4 サイクル（計 5 サイクル）から後を外し、それより前のサイクルは使う。**
   death cycle は mark_h を含むサイクル（mark_h 以前で最後に accepted になった分裂から始まる）。
3. death cycle より後の「分裂」は死んだ細胞の偽イベントなので捨てる。`cycle_fits_review.csv` には
   death cycle より後に始まるサイクルが 6 本ある（例: Pos59 ch09 の 89.75 h の「出生」は体積 318 µm³）。**`cycle_fits_review.csv` をそのまま使わない。**
4. マークが無く 99 h より前に追跡が終わる 18 系列（目視で 90 h 未満にした Pos85 ch07 を含む）は、死亡でなく打ち切りとして使う。Pos 単位で揃って止まっているもの

## 2. 全図に共通の要件

- **n は母細胞とサイクルの両方を書く**（例: n = 3,732 cycles from 105 mother cells）。
- **検定は母細胞を単位にする。**サイクルは母細胞の中で相関する（倍加時間の return map r = 0.72）ので、サイクルを独立に数えると p が小さく出すぎる。
  例: Pos ≤52 と ≥53 の密度の Mann–Whitney は、サイクル単位で p = 1e−109、母細胞の中央値単位で p = 1.5e−5（37 対 68）。
  母細胞ごとの中央値で検定するか、母細胞を random effect にした混合モデルにする。
- **誤差は母細胞を単位にした bootstrap の 95% CI**（母細胞を復元抽出）を基本にする。帯で SD を出すときはそう書く。
- **条件**: *S. pombe*（株は §6 で決める）、YE、温度（§6）、mother machine、5 min/frame、0–100 h、背景は outside_quad、体積は EFD、RI 校正なし（n_medium 1.333）。
- **除外**: 全図のキャプションか Methods で §1 の規則を引く（「死亡系列は death cycle と直前 4 サイクルを除外」）。
- **Pos の偏りが説明されるまで**（fig260908:position_bias）、密度・幅・体積を群で比べる図は Pos の群（今の候補は Pos1–17 と Pos21 以降）を分けて描くか、補正したことを書く。
- 共通の操作的定義（各図のキャプションの★に使う）:
  - サイクル = accepted の分裂から次の accepted の分裂の直前の frame まで。
  - 出生時の値 = サイクル先頭の有効 3 frame の中央値。分裂時の値 = 末尾の有効 3 frame の中央値。
  - 乾燥質量 `phase_mass` = (λ/2πα)·Σφ·A_px（λ = 658 nm、α = 0.18 mL/g、A_px = 0.3457² µm²）。
  - 倍加時間 = ln 2 / k。k はサイクル内の有効 frame で ln(質量) を時刻に直線 fit した傾き（有効 5 点以上）。
  - 間隔 = 次の accepted 分裂の時刻 − この分裂の時刻。
  - 体積 = 黄色輪郭（EFD K=6、縮めない）の中心線に直交する弦を回転体として積分。
  - 密度 = 乾燥質量 / 体積。サイクル平均密度 = サイクル内の有効 frame の密度の平均。
  - 長さ・幅 = 黄色輪郭の長軸（中心線の弧長）・短軸（胴体の弦の平均）。

  (c) 主な量の AUC と 95% CI のサイクルに対する変化、(d) 時間（1 h）ごとの AUC（幅・密度・d ln M/dt・dL/dt）。
- 量の定義: AUC = 死亡系列の値が matched control の中で占める順位の平均。matched control = 同じ Pos 群でマークが無く、最後の分裂の 2 h 後まで追えた系列の、最後の分裂に一番近い分裂（±1.5 h）。onset = −1 から途切れずに null の 95% 帯の外にある一番古いサイクル。
- n: 死亡 39 系列（−12 で 25）、生存 74 系列。null 200 回、bootstrap 1,000 回。
- 今の値: onset は dL/dt と d ln M/dt が −3（約 8 h・7 h 前）、幅が −2〜−3（6 h 前）、密度と generation time が −1（密度は 5 h 前）。分配比・密度のゆらぎ・外れ値の割合は区別できない。
- 決めること: (a) にサイズの行を残すか（分裂時の長さは −3 から短くなる）。本文に出すなら (b)(d) だけでもよい。

### fig260908:around_last_division — 最後の分裂の前後［新・中］
